# Polis 试玩说明（2026-10 原型）

> 你是守护灵：没有身体，不能操控它。它拿不定主意时会低声问你；它会记住你，但它有自己的立场。

## 启动

```bash
npm install
npm run dev:test     # 推荐第一次试玩：测试模式，带"🧪 测试快进"，存档 ./polis-test.db
# 或
npm run dev          # 正式规则：tick = 现实 1 小时，存档 ./polis.db
```

打开 http://localhost:3000 。生产构建试玩：`npm run build && npm run start:test`（或 `npm start`）。

- 两种模式的存档互相隔离；删掉对应的 `.db` 文件即回到空存档。
- 没有配置模型时自动进入 **离线模式（规则引擎）**，右上角会标出来。要接模型：
  `POLIS_LLM_URL=http://<host>:1234/v1/chat/completions POLIS_LLM_MODEL=<model>`
  （兼容旧的 `LMSTUDIO_URL / LMSTUDIO_MODEL`；云端 OpenAI 兼容端点再加 `POLIS_LLM_API_KEY`）。
- 时区默认取浏览器时区（创建 Agent 时记录），否则 `POLIS_TZ`，默认 Asia/Shanghai。

## 第一次（约 3 分钟）

0. **标题画面。** 背景是正在运转的小镇。空存档显示「开始」，已有存档显示「继续 · 名字 · 第 N 天」。
   第一次点击同时解锁浏览器音频（右下角可以关掉或调音量，设置保存在本机）。
1. **起名、选外观 → 让它入城。** 它从城门走进来。
2. **三件事（首会话三岔路）。** Mira 的合作、Nova 的高险单、Sol 的捷径。每个回答都会被
   立刻写成一条"烙印"（原则）。
3. **烙印揭晓 → 看它出发。** 它会按你的回答去做第一批真实的活：和 Mira 合作 / 去外围 /
   给 Tao 送货（提前标记送达还是走完流程）。
4. 金色光圈 = 你守护的 Agent。左上卡片和顶部"当前行动"写着它在做什么、**为什么**
   （例如 `你说「去」` / `你说过『稳定的积累胜过一次豪赌』`）。

## 操作

| 键 | 作用 |
|---|---|
| 拖动 / WASD / 方向键 | 移动镜头（会停止跟随） |
| 滚轮 / 双指 / Q E / − = | 缩放 |
| Space | 找到我的 Agent 并跟随 |
| 1 2 3 | 回应当前岔路的第 1 / 2 / 3 个选项 |
| N / P / R | 留言 / 明信片 / 烙印 |
| F | 小镇动态展开 / 收起 |
| Esc | 关闭最上面的窗口或抽屉 |
| ? 或 H | 按键说明 |

点任意居民或建筑会出现卡片：它在做什么、为什么、和谁熟、谁记着谁的仇（「城里的关系」）。
在输入框里打字时，这些按键不生效。手机上：拖动镜头，双指缩放，底部按钮代替按键。

## 你能做的四件事（全部异步，没有自由聊天）

| 动词 | 在哪 | 说明 |
|---|---|---|
| 回应岔路 | 底部「岔路」 | 只有它自己决定不了时才会来：没有原则 / 两条原则打架 / 赌注大 / 和旧事有关。24 小时不回，它按自己的原则决定 |
| 回应质问 | 自动弹出 | 某条原则让它连续吃亏 ≥2 次（第 5 天起），它会"和 Kade 聊过之后"来问你：重申还是修订 |
| 强制执行 | 它说"不"之后 | 30 Scrip 指令券 + 信任 −10，并留下一条"你曾强迫我"的烙印 |
| 留言 | 底部「留言」 | ≤50 字，每天 3 句。它**不会秒回**，回应写在当晚 23:00 的明信片开头 |

## 快速体验跨日内容（测试模式）

左下角 **🧪 测试快进（仅测试用）**：`+1 小时 / 到今晚 23:00 / 到明早 06:00 / +24 小时`。
快进只是把整个世界的时钟往前推并补跑每个整点——任务时长、24 小时过期、第几天的规则都不变。
顶部会一直显示"已测试快进 X 小时"。

推荐路线：

1. 回答三岔路 → 看它出发 → 留一句言（比如"今天辛苦了"或"这几天稳一点"）。
2. 「到今晚 23:00」→ 读第一张明信片：开头回应你的留言，正文是它今天真实做过的事，
   至少引用一条你的原则。
3. 「到明早 06:00」→ 第 2 天：它会在某个决定里第一次复述你的原则（D2 首次引用）。
4. 继续 `+24 小时` 到第 3-5 天：风险单的结果、终检查出的捷径、谁对谁记了仇、
   它第一次对你说"不"（出现条件见下）。
5. 第 6 天傍晚 Mira 会来找它，提起你第一天的选择；第 7 天晚上有 Iris 的"七日回顾"。

**同一种立场说第二次会怎样？** 不会再长出一条近义的新烙印，而是把已有那条“记得更牢”
（分量回满、重新计时衰减，动态里显示「烙印『…』又深了一层」）。

**它什么时候会拒绝你？** 不是随机的：你选的方向和它自己的某条原则相反，而且数据库里有支持
那条原则的事实（比如最近冒险赔过钱、对方有违约记录、上次走捷径被查出）。第 3 天以前、
或它还没顺从过你两次时，只会"折中"或"照做但提醒你"。

## 看点：哪些是真的

- 城里的每一条动态、每张明信片里的事和数字都来自数据库里的真实记录。
- 6 位居民（Mira / Sol / Tao / Iris / Kade / Nova）和你的 Agent 跑同一套规则：接活、
  找人合作、按记忆接受或拒绝合作、为更好的单子中途毁约、借钱与讨债、记仇（每对最多 5 件）。
- 两段式协作：赶工做出来的零件会让后续运送的成功率从 90% 掉到 60%，失败了，运送的人会
  记做零件的人一笔。

## 画面与资源

- 地图是 Tiled 格式（`public/assets/town/polis-town.tmj`，64×42 格），由 `node scripts/build-town-map.mjs` 生成；
  居民按 A* 路网行走，屋顶 / 树冠在角色上层（走到屋檐下会被遮住）。
- 夜里（19:00 后）画面会压暗，居民回家后头顶出现睡眠符号。
- 当 Agent 站在地图边缘时，镜头会让它避开左侧面板；露出的地图外侧是压暗的地面。
- 素材与字体的授权见 `public/assets/town/CREDITS.md`、`public/assets/audio/CREDITS.md`、`public/assets/ui/CREDITS.md`。

## 已知限制

- 离线模式下"判定器 / 蒸馏 / 明信片"都走规则与模板（界面标"规则判定"/"离线模式"）。
  真实模型下的人格效果在本环境**未验证**。
- 单人存档：一个服务进程只支持一个玩家 Agent。
- 正常速度下小镇每个整点才推进一次逻辑；之间的走动、停留和头顶符号是"表演"，
  与后台状态一致，但不产生后果。
- 离线模式下的烙印文字来自选项预设的模板句，同一领域、同一立场的选择会合并到同一条烙印上；
  更细的措辞差异要靠真实模型。
