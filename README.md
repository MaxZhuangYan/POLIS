# Polis

Polis is a game-like prototype for an AI agent contract economy and society simulation. It is inspired by AI Town, Stanford Smallville / Generative Agents, AIvilization, and Project Sid, but it is not a direct clone of any of them.

The demo focuses on first-impression gameplay: a dark strategy HUD, an active AI society space, agent roles, relationship links, contract missions, world events, work logs, resources, and epoch settlement.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Build and Checks

```bash
npm run typecheck
npm run build
```

`npm run lint` is included for projects using the Next lint command. If your installed Next version no longer exposes `next lint`, use `npx eslint .` instead.

## Local LLM

The simulation route tries LM Studio first:

```bash
LMSTUDIO_URL=http://127.0.0.1:1234/v1/chat/completions
LMSTUDIO_MODEL=gemma-4-4b
```

Start LM Studio's OpenAI-compatible local server and load the Gemma 4 4B model. If the server is offline, Polis falls back to deterministic mock logs so the demo still runs.

## Implemented

- Agent Lab with selectable and creatable agents.
- Society Space with map regions, moving-world ambience, and relationship edges.
- Mission Board with dispatch actions.
- Work Log Terminal generated by LM Studio or mock fallback.
- World Feed with social, contract, rule, culture, and settlement events.
- Epoch Settlement and resource updates for Scrip, Reputation, Compute, and Contribution.
- localStorage persistence and reset.

## Mocked

- Agents, missions, contracts, settlement math, and relationship values are mock data.
- No database, wallet, token, NFT, or chain interaction is included.
- The simulation is intentionally lightweight and client-driven, with one optional local LLM route for flavor text.

## Research Notes

- AI Town: virtual town where AI characters live, chat, and socialize; strong visual town metaphor and real-time simulation loop.
- Stanford Generative Agents / Smallville: believable agents need memory, reflection, planning, observation, and emergent social coordination.
- Project Sid: emphasizes 10 to 1000+ agents, PIANO-style coherence, role specialization, collective rules, cultural propagation, social graphs, and civilizational progress metrics.
- AIvilization: points toward public large-scale AI society sandboxes with resource constraints, production, trade, governance, adaptive profiles, and human steering.

## Product Direction

Polis should differ from AI Town by making work, contracts, contribution, settlement, and governance the primary loop rather than casual daily-life chat. It should differ from Project Sid by using a playable command-center interface instead of a Minecraft research environment. The next step is to connect real agent memory, a durable event store, and local or hosted LLM workers for continuous multi-agent simulation.
