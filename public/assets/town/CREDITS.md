## What is used

| File | Origin |
| --- | --- |
| `tileset.png` | `background-elements/tileset.png` (28 x 40 tiles of 16 x 16). Extruded by 1 px (margin 1, spacing 2) by `scripts/extrude-tileset.py`, and extended with a few **derived** tiles (rows 40+: concave road corners computed from the original edge tiles, a collision marker). |
| `characters/{1,3,5,6,13,14,16,17,25}.png` | `characters/<n>.png` — 16 x 16 frames, 4 columns (down, up, left, right) x 7 rows |
| `characters/dog.png` | `characters/dog.png` |
| `faceset/{1,3,5,6,13,14,16,17,25}.png` | `characters/faceset/<n>.png` (38 x 38 portraits) |

The Tiled map `polis-town.tmj` is generated by `scripts/build-town-map.mjs` (see that file for the layout data and
the layer / object conventions) and can be opened and edited in the Tiled editor.

The emote icons the town also draws (`/assets/aiv/ui/icon-*.png`) are not part of this pack.
